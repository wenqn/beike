# Python 基础语法

## 1. 变量：给数据贴标签
```python
name = "小明"
age = 16
score = 98.5
```
- `=` 是**赋值**，不是等于
- 左边名字，右边数据
- 想改就直接重新赋值

### 变量名命名规则
- 不能以数字开头
- 只能用字母、数字、下划线`_`或其组合，不能用其他特殊字符（如 `@`、`!` 等）
- 区分大小写
- 建议用下划线 `_` 分隔单词
- 建议用有意义的名字，能看出是什么数据


## 2. 运算符：Python 的小算盘
### 算术运算
- `+ - * /` 加减乘除
- `/` 除法（结果总是小数）
- `//` 整除（只取整数，向下取整）
- `%` 取余数（取除数的余数）
- `**` 次方

### 比较运算
- `> < >= <= == !=`
- 结果只有 **True / False**

### 布尔运算
- `True` 真
- `False` 假
  
  - 首字母大写
  - 非0的数字，数学上成立，符合预定规则的都是`True`(`真`)
  - 0的数字，数学上不成立，不符合预定规则的都是`False`(`假`)
  - 比较、逻辑运算都会出布尔值

### 逻辑运算
- `and` 并且：两个都真才真
- `or` 或者：一个真就真
- `not` 非：真变假，假变真

### 合并运算符（海象 :=）
```python
if (n := len("hello")) > 3:
    print(n)
```
一边赋值，一边判断，少写一行

### 运算优先级（从高到低）
1. 括号 `()` 最牛
2. 次方 `**`
3. 乘除 `* / // %`
4. 加减 `+ -`
5. 比较 `> < ==`
6. 逻辑 `not > and > or`
7. 赋值 `=`

一句话记：**括号优先，先算乘除，后算加减；先计算再比较，然后逻辑最后赋值**

## 3. 数据类型
### ① 字符串（文字）
```python
s = "我是文字"
s = '单引号也行'
```
- 拼接：`"a" + "b"`→`"ab"`
- 重复：`"哇" * 3`→`"哇哇哇 "` '\n'
        `"哇奥" * 3 `→ `??`    
- 长度：`len("hello！")`→`6`
- 取第1个：`s[0]`→`"h"`

### ② 数字
- 整数 `10`
- 小数 `9.9`

### ③ 布尔（真假）
- `True` 真
- `False` 假
- 比较、逻辑运算都会出布尔值

### ④ 列表（装一堆东西）
```python
lst = [1, "苹果", True]
```
- 符号：[],里面可以放任意类型数据 
- 不同数据用英文逗号隔开
- 取第1个：`lst[0]`，序号从`0`开始
- 加东西：`lst.append(新东西)`,加在列表最后侧

## 4. 程序控制
### ① 判断 if
```python
if score >= 60:
    print("及格")
elif score >= 90:
    print("优秀")
else:
    print("加油")
```
- 必须 **冒号 + 缩进**
- 条件对了才执行

### ② 循环 for
```python
for i in range(3):
    print("跑一圈")
```
- 重复做事情
- 不用写好几遍

### range()函数
- 生成一个序列，序列中的元素从0开始，到指定的数字结束
- 例如：`range(3)`→`[0, 1, 2]`
- 例如：`range(1, 4)`→`[1, 2, 3]`
- 例如：`range(1, 4, 2)`→`[1, 3]`
- 生成的序列是个列表，用`[]`括起来
- 可以用`for`循环来遍历这个序列，执行重复的操作
- 
### ③ 自定义函数 def
```python
def say_hi():
    print("你好！")
```
- 打包代码，想用就调用
